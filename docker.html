🐳 Docker Cheat Sheet

Guia rápido de Comandos CLI, instruções Dockerfile e Docker Compose

📦 Gerenciamento de Containers

Ciclo de vida e execução de containers.

Comando Descrição
docker run -d -p 80:80 nginx Roda um container em background (detached) mapeando a porta 80
docker run -it ubuntu bash Roda um container interativo com terminal
docker ps Lista containers em execução
docker ps -a Lista todos os containers (inclusive parados)
docker stop <id> Para um container em execução de forma graciosa
docker rm <id> Remove um container (precisa estar parado)
docker rm -f <id> Força a parada e remove o container

💿 Gerenciamento de Imagens

Download, criação e remoção de imagens Docker.

Comando Descrição
docker pull <imagem> Baixa uma imagem do Docker Hub
docker build -t app:v1 . Constrói uma imagem a partir do Dockerfile no diretório atual
docker images Lista imagens armazenadas localmente
docker rmi <id_imagem> Remove uma imagem local
docker push <usuario/img> Envia uma imagem para um Registry (ex: Docker Hub)

🛠️ Operações e Debugging

Interagindo com containers em execução.

docker exec -it <id> sh Abre um terminal dentro de um container rodando
docker logs <id> Exibe os logs do container
docker logs -f <id> Acompanha os logs em tempo real (follow)
docker top <id> Mostra os processos rodando no container
docker inspect <id> Exibe detalhes de baixo nível (JSON) do container/imagem
docker stats Mostra uso de CPU, RAM e Rede em tempo real

📝 Dockerfile (Instruções)

Como escrever a "receita" para sua própria imagem.

# 1. Imagem Base
FROM node:18-alpine

# 2. Diretório de Trabalho (onde os comandos rodarão)
WORKDIR /app

# 3. Copia arquivos (host -> container)
COPY package.json ./

# 4. Executa um comando durante o build
RUN npm install

# 5. Copia o restante dos arquivos
COPY . .

# 6. Define variável de ambiente
ENV NODE_ENV=production

# 7. Documenta a porta que será usada
EXPOSE 3000

# 8. Comando executado ao iniciar o container
CMD ["npm", "start"]

🐙 Docker Compose (Comandos CLI)

Orquestração de múltiplos containers.

docker-compose up -d Cria e inicia os serviços em background
docker-compose down Para e remove containers, redes e volumes associados
docker-compose stop Apenas para os serviços (sem remover)
docker-compose start Inicia serviços que estavam parados
docker-compose build Reconstrói as imagens dos serviços
docker-compose logs -f Visualiza logs de todos os serviços (ou logs -f <servico>)
docker-compose ps Lista os containers gerenciados pelo compose

📄 Estrutura docker-compose.yml

Definição de infraestrutura multi-container via YAML.

version: '3.8'

services:
  frontend:
    image: nginx:alpine
    ports:
      - "80:80"
    depends_on:
      - backend

  backend:
    build: ./meu-backend # Usa Dockerfile local
    environment:
      - DB_HOST=database
      - DB_PASS=secreta

  database:
    image: postgres:13
    volumes:
      - db-data:/var/lib/postgresql/data

# Declaração de volumes persistentes nomeados
volumes:
  db-data:

🧹 Limpeza de Sistema (Prune)

docker system prune Limpa containers parados, redes não usadas, imagens sem tag (dangling) e cache de build
docker system prune -a Remove TUDO que não estiver sendo usado (incluindo imagens com tag)
docker volume prune Remove volumes que não estão atachados a nenhum container

🖧 Redes e Volumes

docker network ls Lista as redes Docker
docker network create <nome> Cria uma nova rede isolada
docker volume ls Lista volumes nomeados
docker volume create <nome> Cria um volume persistente
