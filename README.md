# DVP Cheatsheets

Coleção de **Cheat Sheets (folhas de consulta rápida)** para ferramentas DevOps e Infrastructure as Code, focadas no uso diário e prático.

Cada arquivo é um **HTML autônomo**, responsivo, com tema visual da ferramenta, otimizado para impressão em PDF (botão 🖨️ no canto inferior direito) e leitura offline.

## 🎯 Objetivo

Servir como **referência rápida** durante o dia a dia de trabalho com DevOps — sem precisar buscar na documentação oficial toda vez que você esquece a sintaxe de um `docker-compose.yml`, um `terraform import`, um módulo `ansible.builtin.apt`, um `needs:` no GitHub Actions ou um `rules:` no GitLab CI.

---

## 🖨️ Como usar

1. Faça o clone do repositório ou baixe o `.html` desejado
2. **Abra o `.html` diretamente no navegador** (duplo clique ou `open arquivo.html`)
3. Use o botão **🖨️ Imprimir PDF** no canto inferior direito para gerar um PDF limpo (estilo A4, sem o botão)
4. Funciona **100% offline** — sem dependências externas, CDN ou build step
