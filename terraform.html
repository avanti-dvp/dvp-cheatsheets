🏗️ Terraform Cheat Sheet

Guia rápido de comandos, estado e estrutura HCL para Infraestrutura como Código

🔄 Fluxo de Trabalho Principal (Core Workflow)

O ciclo de vida básico de qualquer projeto Terraform.

Comando Descrição
terraform init Inicializa o diretório, baixa providers e módulos
terraform plan Gera e exibe um plano de execução (o que vai mudar)
terraform apply Aplica as mudanças reais na infraestrutura
terraform destroy Destrói todos os recursos gerenciados pelo projeto

⚡ Opções Úteis do CLI

apply -auto-approve Aplica alterações sem pedir confirmação manual (yes)
plan -out=plano.tfplan Salva o plano de execução em um arquivo
apply "plano.tfplan" Aplica um plano previamente salvo
apply -replace="recurso" Força a recriação de um recurso específico (substitui o antigo taint)

🗂️ Gerenciamento de Estado (State)

Interações diretas com o arquivo terraform.tfstate.

Comando Descrição
terraform state list Lista todos os recursos rastreados no estado
terraform state show <id> Exibe os detalhes e atributos de um recurso
terraform state mv <src> <dst> Move um recurso no estado (renomear/refatorar)
terraform state rm <id> Remove recurso do state (NÃO destrói na nuvem)
terraform refresh Atualiza o state com a infraestrutura real (Implícito no plan/apply)
terraform import <addr> <id> Mapeia um recurso já existente na nuvem para o state

📁 Estrutura Padrão de Arquivos

  • main.tf: Recursos principais e lógica.
  • variables.tf: Declaração de variáveis de entrada.
  • outputs.tf: Valores retornados após o apply.
  • providers.tf: Configuração de provedores (AWS, Azure, etc).
  • terraform.tfvars: Valores atribuídos às variáveis.

📝 Sintaxe Básica (HCL)

Estrutura dos blocos principais do Terraform.

# 1. Configuração do Provider
provider "aws" {
  region = "us-east-1"
}

# 2. Criação de um Recurso
resource "aws_instance" "web" {
  ami           = var.ami_id
  instance_type = "t2.micro"
  
  tags = {
    Name = "WebServer"
  }
}

# 3. Variável de Entrada
variable "ami_id" {
  description = "ID da Imagem"
  type        = string
  default     = "ami-123456"
}

# 4. Variável de Saída (Output)
output "ip_publico" {
  value = aws_instance.web.public_ip
}

🛠️ Formatação e Validação

terraform fmt Reescreve os arquivos para o padrão canônico (formatação visual)
terraform fmt -check Verifica se os arquivos estão formatados sem alterá-los
terraform validate Verifica se a sintaxe e os argumentos HCL são válidos e consistentes

📦 Módulos (Modules)

Agrupamento de recursos para organização e reutilização de código infraestrutural.

# Chamando um módulo local (sua própria pasta)
module "vpc_custom" {
  source = "./modules/vpc"
  
  # Passando variáveis exigidas pelo módulo
  cidr_block = "10.0.0.0/16"
  ambiente   = "producao"
}

# Chamando um módulo do Terraform Registry
module "s3_bucket" {
  source  = "terraform-aws-modules/s3-bucket/aws"
  version = "~> 3.0"

  bucket = "meu-bucket-exemplo"
}

Dica: Sempre que adicionar um novo módulo ou alterar seu source, você precisará rodar terraform init (ou terraform get) para que o Terraform faça o download do código dele.

🌍 Workspaces (Ambientes)

Isolamento de estado para múltiplos ambientes (ex: dev, prod) no mesmo diretório.

terraform workspace show Exibe o workspace atual
terraform workspace list Lista todos os workspaces
terraform workspace new <nome> Cria e muda para um novo workspace
terraform workspace select <nome> Alterna para um workspace existente
