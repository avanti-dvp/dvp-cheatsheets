⚙️ Ansible Cheat Sheet

Guia rápido de comandos, módulos e estruturas para o dia a dia

🛠️ Conceitos Básicos & Configuração

Comando / Arquivo Descrição
ansible --version Exibe a versão instalada do Ansible
/etc/ansible/hosts Arquivo de inventário padrão
/etc/ansible/ansible.cfg Arquivo de configuração padrão

📡 Inventário e Conectividade

Testar a comunicação e listar os hosts definidos no inventário.

Comando Descrição
ansible all -m ping Testa conexão com todos os hosts
ansible all --list-hosts Lista todos os hosts gerenciados
ansible webservers -m ping Testa conexão só com o grupo webservers
ansible -i custom_hosts all -m ping Usa arquivo de inventário customizado

⚡ Comandos Ad-Hoc

Executar tarefas rápidas sem criar playbook.

Sintaxe: ansible <hosts> -m <modulo> -a "<args>" [opções]

Opções Frequentes:
  • -b ou --become: Privilégios de superusuário (sudo).
  • -K ou --ask-become-pass: Pede a senha do sudo.
  • -u <usuario>: Usuário para conectar via SSH.
Exemplos Práticos: 
# Verificar uptime de todos os servidores
ansible all -a "uptime"

# Instalar o Nginx (apt)
ansible webservers -m apt -a "name=nginx state=present" -b

# Reiniciar um serviço
ansible dbservers -m service -a "name=mysql state=restarted" -b

# Copiar arquivo local para remotos
ansible all -m copy -a "src=/local/arq.txt dest=/tmp/arq.txt"

📦 Módulos Essenciais

Módulo Função Principal Exemplo de Argumentos
ping Testa conectividade SSH/Python (Sem argumentos)
setup Coleta fatos (facts) do host filter=ansible_os_family
command Executa comandos (sem pipes) uptime
shell Executa comandos (c/ pipes) cat /etc/passwd | grep root

file Gerencia arquivos/diretórios path=/tmp/dir state=directory
user Gerencia usuários name=joao state=present

📜 Playbooks

Arquivos YAML que definem o estado desejado.

Comando Descrição
ansible-playbook site.yml Executa o playbook
ansible-playbook site.yml --syntax-check Verifica a sintaxe YAML
ansible-playbook site.yml --check Dry run (Simula execução)
ansible-playbook site.yml -l srv1 Executa num host específico
ansible-playbook site.yml -t "deploy" Executa tarefas com a tag específica
Estrutura Básica (exemplo.yml): 
---
- name: Instalar e iniciar servidor Apache
  hosts: webservers
  become: yes
  
  tasks:
    - name: Garantir que o apache2 está instalado
      apt:
        name: apache2
        state: present

    - name: Garantir que o serviço está rodando
      service:
        name: apache2
        state: started
        enabled: yes

🧩 Roles (Papéis)

Maneira de agrupar tarefas, variáveis e arquivos de forma padronizada e reutilizável.

Estrutura Padrão de Diretórios:
  • tasks/ - As ações principais (main.yml).
  • handlers/ - Handlers acionados por tarefas.
  • defaults/ - Variáveis padrão (menor prioridade).
  • vars/ - Variáveis da role (maior prioridade).
  • files/ - Arquivos estáticos (para o módulo copy).
  • templates/ - Templates Jinja2 (para o módulo template).
  • meta/ - Dependências da role.
Como usar no Playbook: 
---
- hosts: webservers
  roles:
    - common
    - role: nginx
      vars:
        porta_padrao: 8080

🔐 Ansible Vault

Ferramenta para criptografar dados sensíveis.

ansible-vault create arq.yml Cria arquivo criptografado
ansible-vault edit arq.yml Edita arquivo existente
ansible-vault encrypt arq.yml Criptografa arquivo existente
ansible-vault decrypt arq.yml Descriptografa arquivo 
# Executando playbooks com Vault
ansible-playbook site.yml --ask-vault-pass
ansible-playbook site.yml --vault-password-file ~/.senha

🌌 Ansible Galaxy

Gerenciamento de Roles do Ansible.

ansible-galaxy install <role> Instala uma role
ansible-galaxy init <nome> Cria estrutura base para role
ansible-galaxy list Lista roles instaladas
